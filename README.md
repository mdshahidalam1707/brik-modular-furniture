# BRIK — Build Your Space

A premium modular furniture landing page created as a **Front-End Development Internship Assignment**.

BRIK reimagines the concept of building blocks as a modern modular furniture system — allowing people to build, rebuild, expand, and personalize their living spaces.

> **Don't buy furniture. Build it.**

## 💡 Concept

The assignment required reimagining a well-known brand into a completely different product category.

For this project, I transformed the **building-block concept into a premium modular furniture brand called BRIK**.

### The idea

Traditional furniture is fixed.

BRIK is designed to evolve.

Users can combine different furniture modules to create configurations for:

* Living rooms
* Lounges
* Workspaces
* Storage
* Small apartments
* Larger family spaces

The goal was to create a landing page that feels like a real premium furniture startup rather than a typical assignment website.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mdshahidalam1707/brik-modular-furniture.git
```

### 2. Navigate to the project

```bash
cd brik-modular-furniture
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
